# Status Icon

Plugin that automatically renames files based on the value of their `status` property.

It adds a corresponding emoji at the beginning of the file name, making it easier to identify and manage notes in the File Explorer, General and Kanban views.

### Customization

The plugin includes settings that allow you to:
* Set custom icons for different statuses.
* Define custom keywords that trigger specific icons.
* Customize how your notes are visually identified based on their properties.

The goal is simple: make managing notes easier and improve visual organization across your Obsidian workspace.
